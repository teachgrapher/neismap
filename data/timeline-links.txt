# 나이스 지도 항목 ↔ 나이스 타임라인 업무카드 연결표 (사람이 고치는 원본)
#
# 한 줄 = 지도 항목 하나.  형식:  항목id  문서번호:카드id  문서번호:카드id ...  [? 애매한 이유]
#   - 항목id    : partN.html 의 PART 데이터에 있는 가지 끝 항목 id (s1a, p11a 등)
#   - 문서번호  : 아래 '@번호 파일이름' 줄로 정한 별칭. 카드id 는 문서 안 article id(t14 등)
#                 번호는 이 파일 안에서만 쓰는 이름이라 타임라인에 문서가 늘어도 바뀌지 않는다
#   - '-'       : 연결할 카드가 없음(링크를 달지 않음)
#   - '? 이유'  : 짝이 애매해 검토가 필요한 줄. 확정되면 ? 뒤를 지워도 된다
# 쪽수는 짝 판단에 쓰지 않는다(지도는 하반기, 타임라인은 상반기 매뉴얼 기준이라 쪽 번호가 다름).
# 고친 뒤에는  python3 tools/build_timeline_links.py  로 두 사이트의 링크 파일을 다시 만든다.
